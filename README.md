Dalyviai:

- Pardavėjas
- Pirkėjas
- Kurjeris

Funkcijos (teisės):

Pardavėjas:

- paskelbti prekę, kainą
- patvirtinti pirkėjo užsakymą
- paskirti kurjerį
- gauti mokėjimą

Pirkėjas:

- peržiūrėti prekę (UI)
- užsakyti prekę (sumokant sutartin)
- atšaukti dar nepatvirtintą užsakymą (ir susigrąžinti mokėjimą)
- patvirtinti prekės gavimą

Kurjeris:

- patvirtinti, kad prekė pristatyta
